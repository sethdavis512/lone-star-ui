Add `OtpField` (One-Time Password Field), the last Base UI primitive missing from the library. Exports `OtpFieldRoot`, `OtpFieldInput`, and `OtpFieldSeparator`, built on `@base-ui/react/otp-field` with the Texas token palette. Available via the `lone-star-ui/otp-field` subpath. The library now has full parity with Base UI's component set.
